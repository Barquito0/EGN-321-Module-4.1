# Streamlit Deployment Checklist

- [x] `app.py` created and connected to the tested solver.
- [x] `requirements.txt` contains required packages.
- [x] Repository is pushed to GitHub.
- [x] No secrets or private data are committed.
- [ ] Streamlit Community Cloud app points to the correct repository and branch.
- [ ] Public application opens successfully.
- [ ] At least one valid case works in deployed app.
- [ ] Invalid input is refused in deployed app.
- [ ] Non-convergence is demonstrated in deployed app.
- [ ] README contains the public URL.
